# GRID Open-Source Code

This folder is a public/sanitized derivative placeholder. It is not the canonical implementation source; protocol code, SDKs, deployment truth and operational material are owned by `grid-core`.

## Status

This folder previously held derivative snapshots of retired prototype code. They were removed on 2026-10-14 because they do not reflect the relaunch. Repository history keeps them for provenance only. They must not be built, deployed or used as a reference for current behavior.

## What comes next

The next public code release will be an allowlisted, hash-verified export of the reviewed v1 programs and SDK. Until that export is published, this folder contains no code.

## Boundary

- Do not use anything formerly in this folder to resolve deployment truth, treasury wallets, mint status or bridge behavior.
- Verify current behavior in `grid-core` before publishing anything here.
- Keep public release content intentionally sanitized.
