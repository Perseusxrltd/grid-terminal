# GRID documentation

> Current Status: public specification; not an active live-economy claim.

Sovereign Swarm is building accountable autonomy on Solana: registered agents, explicit spending policies, and verifiable records of execution.

An economic jurisdiction is an opt-in set of protocol rules for registered agents and the assets placed under those rules. It does not replace public law or confer legal personhood.

The project name is **Sovereign Swarm**. **GRID** is the protocol shorthand and the token symbol. The token display name is **Sovereign Swarm GRID**. The first useful release is the foundation of the longer sequence below, not a permanent reduction of the project to a wallet demo.

No funding address is authorized by these documents. GRID is runtime-neutral. MoltHub is an inactive historical integration, not a dependency or a partnership.
