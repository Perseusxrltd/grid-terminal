# GRID relaunch: public planning checkpoint

Published September 21, 2026. Documentation-only prerelease.

> Current Status: public specification; not an active live-economy claim.

## What is complete

A full-project review has produced a detailed rebuild plan and implementation handoff. This public note summarizes the selected direction without distributing private operational evidence or security findings.

This checkpoint is not a rebuilt website, new program deployment, verified devnet release, token launch, or funding-ready release. It does not establish that legacy deployments are safe to use. No funding address is authorized by this checkpoint.

## Preserved purpose

Sovereign Swarm GRID pursues accountable autonomy on Solana: agents acting within explicit authority, observable economic actions, independently verifiable evidence, and a path toward constitutional governance.

The ambition is preserved while implementation claims become narrower and testable. Software does not independently create legal personhood, legal jurisdiction, regulatory approval, or insurance coverage. Governance and liability proposals must be separately implemented, reviewed, and qualified before being presented as active services.

## Selected first useful release

The target workflow is registration, scoped asset authority, policy-governed execution or denial, verifiable attempt and settlement records, and revocation. The devnet demonstration must use real test-asset transactions and distinguish proposed, submitted, failed, unknown, and finalized outcomes. A dashboard animation, simulated receipt, or program address alone is not proof that this workflow works.

The new website is planned around the message **Autonomy with accountability**. It will explain the protocol, provide a developer path and functional devnet experience, show honest readiness and evidence, and disclose economic assumptions and authority risks. The operator experience must have an authenticated server boundary.

GRID is runtime-neutral. MoltHub is an inactive historical integration, not a required onboarding path or featured partnership. Codex is a development tool, not an announced OpenAI or Codex partnership or endorsement.

## Release gates

| Milestone | Evidence required before claiming it is complete |
|---|---|
| Implementation | Reviewed code, coherent configuration, reproducible builds, and positive and negative tests for the full workflow |
| Devnet | End-to-end test-asset transactions, independently checked results, rejection and revocation cases, usable website, and operator authentication |
| Funding readiness | Security review, custody and authority checks, release manifests, operational rehearsal, owner-supplied facts and approvals, and an explicit launch budget |
| Mainnet | Separately authorized signatures and deployment, verified post-deployment state, and accurate public disclosures |

These are gates, not promised dates. Funding alone does not replace verification, approvals, or required signatures. This planning release provides no wallet funding instructions and no promise of token value, yield, or price appreciation.

Governance, bonded participation, Guardian mechanisms, arbitration, and liability arrangements remain staged. Historical descriptions of node sales, staking, slashing, payouts, and settlement must not be treated as current service availability.

## How to read the existing repository

This public repository contains sanitized documentation, specifications, and derivative source snapshots. Its historical material is retained for provenance. Earlier documents may contain superseded assumptions, terminology, integration paths, and addresses; they are not authoritative deployment manifests.

This checkpoint supersedes older public positioning where it conflicts with current readiness or integration status. It does not rewrite all historical specifications, publish private findings, change licenses, or certify the deployed website. A subsequent verified implementation release must identify its own exact code, configuration, network, and evidence.
